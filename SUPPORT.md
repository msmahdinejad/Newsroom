# Support

## Getting help

For usage questions:

1. Read [README.md](README.md) and
   [docs/deployment.md](docs/deployment.md).
2. Run the safe diagnostics:

   ```bash
   uv run newsroom health
   docker compose ps
   ```

3. Search existing GitHub issues.
4. Open a GitHub issue with the appropriate template if the problem remains.

Include the operating system, Python and Docker versions, project commit,
affected service, safe status output, reproduction steps, and what you
expected. Redact environment values, URLs containing credentials, cookies,
phone numbers, chat/user IDs, proxy details, and source content.

## Scope

Community support is best-effort. Maintainers can help with reproducible
project defects, documented deployment paths, and contributor workflows.
They cannot provide provider quota, platform account recovery, proxy/VPN
access, legal advice, or guaranteed support for upstream website changes.

Use [SECURITY.md](SECURITY.md), not a support issue, for vulnerabilities.
